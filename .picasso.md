> **Mercury Hybrid** (applied 2026-09-21), adapted from Picasso **Preset #23
> "Mercury Hybrid"** (`~/.claude/skills/picasso/presets/mercury-hybrid/`) — the
> direction locked on the ORE research console. Implemented here as a **token
> remap** of `src/app/globals.css` + a font swap in `src/app/layout.tsx`; light +
> dark are one token swap. No component hardcodes a colour — everything reads the
> tokens below.

## Direction in one line

**Mercury-hybrid wealth console.** Mercury's calm, spacious chrome — cool
neutrals, one **indigo/periwinkle** accent (`#5B5BD6` light · `#8886FF` dark),
**Instrument Sans** UI, 12px cards, a whisper of shadow, roomy padding, dark bold
headings — wrapped around **dense IBM Plex Mono figures** for scanning balances,
transactions and positions fast. **Sans for chrome, mono for numbers. No glow, no
gradients.** Light is the primary look; dark is the exact same system on cool
near-black. Depth = 1px borders + surface lift + a whisper of shadow.

## Dials

| Dial | Value | Rationale |
|---|---|---|
| VISUAL_DENSITY | **7** (tables/figures) / **4** (chrome) | Scanning many transactions/positions; roomy sans chrome around dense mono numbers. |
| MOTION_INTENSITY | **3** | Finance tool — hover states + short fades only. No scroll choreography. Respect `prefers-reduced-motion`. |
| DESIGN_VARIANCE | **4** | Strong, quiet POV; conventional tabular structure stays legible, not avant-garde. |

### Rules
- **Never** pure `#000`, pure white, or untinted gray — every neutral is
  cool-tinted toward the indigo.
- `--primary` (indigo) is the only chrome accent: links, active/selected state,
  focus ring, primary buttons, key stat values. **No second chrome hue** — no
  Apple blue, no teal, no purple.
- `--success`/`--error` (green/red) used **only** for signed values — deltas,
  gain/loss, up/down change badges, sparklines. Never for chrome.
- `--info` is aliased to the indigo accent (no separate blue).
- Multi-series **data-viz palettes** are the one exception where extra hues are
  allowed (`useChartTheme().palette`), and they lead with the indigo.

## Typography

Two families, scoped by role (loaded via `next/font` in `layout.tsx`):

- **Instrument Sans** (`--font-sans`) — all chrome: headings, labels, buttons,
  nav, cards, forms, tabs, sidebar.
- **IBM Plex Mono** (`--font-mono`) — numeric figures: `.stat-value`,
  `.font-data`, transaction/amount columns, `code`, chart price labels. **Never
  the whole page; never inside chrome text.**

- **Always** `font-variant-numeric: tabular-nums` on any column/row of numbers so
  digits align (`.font-data`, `.stat-value` already do).
- Section headings: sentence case, 600 weight, `-0.01em`, `--foreground` — weight
  and colour carry hierarchy. Uppercase only for small `.label-caps` / column
  headers (tracked, `--foreground-muted` / `--accent-head`).

## Spatial system

- **Radii:** 12px cards/panels (`.card`, `--radius-md`) · 8px buttons, inputs,
  chips, segments (`--radius-sm`). Logos/avatars are circles.
- **Depth = borders + surface + a whisper of shadow.** `--shadow-sm` is one soft
  level; 1px `--card-border` borders and the `--card` lift carry the rest. No
  heavy drop shadows, no glow, no gradient fills.
- Wide tables scroll inside their own container (`.scroll-hint` / `overflow-x`),
  never the page. Pin identity columns; keep numeric columns right-aligned.

## Component notes (PocketWatch's real elements)

- **Cards** (`.card`, `.card-interactive`) — `--card` fill, 1px `--card-border`,
  12px radius, `--shadow-sm`; hover lifts border to `--card-border-hover`.
- **Buttons** — `.btn-primary` (indigo fill), `.btn-secondary` (card fill + border,
  hover to `--background-secondary`), `.btn-ghost` (text + `--primary-subtle`
  hover). Focus ring = `0 0 0 3px var(--primary-muted)`.
- **Badges / change badges** — `.badge-*` pill uses the semantic tint; signed
  deltas use `.change-badge-up`/`-down` (green/red only).
- **Stat values** — `.stat-value` / `.font-data`: IBM Plex Mono, `tabular-nums`.
- **Inputs** — `--background` fill, 1px border, 8px radius, indigo focus ring.
- **Sidebar / nav** — active item = indigo text on `--primary-muted` wash.
- **Material Symbols** — icons stay; tint with `--foreground-muted` / `--primary`.
- **Charts** — `useChartTheme()` reads the live tokens, so the primary series is
  the indigo accent automatically; green/red only for signed/directional lines.

## Do
- Instrument Sans for chrome, IBM Plex Mono for numbers/figures/code.
- Keep `tabular-nums` on every number. One indigo accent for structure + active
  state; green/red strictly for signed values.
- Cool-tinted neutrals; borders over shadows; light-primary with dark parity via
  the token swap.

## Don't
- ❌ No Apple blue / Tailwind blue / second accent hue. No DM Sans / Inter /
  system-ui as the primary chrome font.
- ❌ No glow, no gradient backgrounds, no heavy drop shadows.
- ❌ No pure `#000`, pure white, or untinted gray.
- ❌ No mono on the whole page (scope it to numbers); no sans inside numeric
  figures.
- ❌ No green/red for anything that isn't a signed value.

## Anti-slop guardrail

The failure mode is "generic fintech SaaS dashboard": Apple/Tailwind blue + DM
Sans + big soft shadows + everything roomy with no real numeric density. Mercury
Hybrid is cooler, quieter, and denser: cool neutrals, one indigo, borders over
shadows, and genuinely compact mono figures. If a screen drifts back toward the
old Apple-blue look, pull it to cool neutrals, single indigo, mono figures,
`tabular-nums`, no glow.
